# Patinhas de Amor 🐾

## Sobre o projeto

O Patinhas de Amor é um projeto de site desenvolvido para uma ONG de proteção animal. O objetivo é apresentar a organização, divulgar animais disponíveis para adoção e mostrar diferentes formas de ajudar.

## Tecnologias utilizadas

- HTML5: estrutura e organização das páginas.
- CSS3: estilização, layout, responsividade e design da aplicação.
- JavaScript: implementação das interações e funcionalidades do site.
- Git e GitHub: controle de versão e gerenciamento do projeto.

## Funcionalidades

- Menu de navegação.
- Submenu de navegação.
- Menu responsivo para dispositivos menores.
- Formulário de cadastro.
- Modal de agradecimento.
- Alertas de cadastro.
- Badges de disponibilidade dos animais.
- Animações utilizando a biblioteca AOS.

## Estrutura do projeto

O projeto está organizado em arquivos e pastas para facilitar sua manutenção:

- `index.html`: página principal do site.
- `cadastro.html`: formulário de cadastro.
- `css/`: arquivos de estilização.
- `js/`: arquivos JavaScript.
- `images/`: imagens utilizadas no projeto.
- `README.md`: documentação do projeto.

## Pré-requisitos

Para executar o projeto, é necessário apenas um navegador atualizado e um editor de código, como o Visual Studio Code.

## Como executar

1. Baixe ou clone o re1. positório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo index.html em um navegador.
4. Navegue pelas funcionalidades disponíveis no site.

## Versionamento

O projeto utiliza Git e GitHub para controle de versões. Foram utilizadas as branches master, develop e feature/menu para organizar o desenvolvimento.
